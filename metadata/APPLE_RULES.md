Sources checked 2026-10-23:
https://developer.apple.com/app-store/product-page/ — name/subtitle 30 characters, keywords 100 total characters with comma separators, no spaces after commas. Avoid repeating name/company/category, irrelevant or competitor brands. Description plain text maximum 4000 characters; promotional text 170.
https://developer.apple.com/help/app-store-connect/reference/app-information/app-information/ — name 2-30 characters.
https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/ — describes keywords as 100 bytes, inconsistent with product page. We use owner-requested/product-page 100 character cap, record UTF-8 bytes transparently, do not claim verified App Store acceptance.
https://developer.apple.com/forums/thread/705360 — community API observation: count Unicode scalar characters, not visual glyphs; not binding Apple staff policy. Avoid emoji/combining sequences. Normalize NFC; verify codepoints and UTF-16 units <= limits.
https://developer.apple.com/app-store/review/guidelines/#subscriptions — subscription disclosures should be clear. Do not invent product names, periods, prices, trials or entitlements. Owner requested generic subscription information; frozen project has no configured product ID. Phrase conditionally if user chooses an auto-renewing subscription; do not advertise a currently working subscription or invent paid feature access.
